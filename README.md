# AI 内容工作台固定部署入口

这是 AI 内容工作台的固定部署入口。仓库只保存公开安装说明、安装器和版本校验清单，不保存客户包、API Key、登录态、客户资料或带签名的限时链接。

## 给使用者

把下面这句话和服务方单独发给你的“部署票据链接”一起交给 Codex：

```text
请按这个固定部署入口帮我升级 AI 内容工作台：先只读检查电脑、当前工作台、版本清单和部署票据；告诉我将更新什么、备份到哪里、哪些内容不会动。等我明确同意后，再下载、校验、备份、安装并生成验收回执。入口：https://github.com/gaofan679-ui/ai-content-workbench-deploy/blob/main/CODEX_DEPLOYMENT.md；部署票据：<服务方单独发送的限时链接>
```

详细步骤见 [CODEX_DEPLOYMENT.md](CODEX_DEPLOYMENT.md)。

## 安全边界

- GitHub 负责固定入口、公开安装器和不可变版本清单。
- 客户包使用私有仓库授权或对象存储签名链接，不进入本仓库。
- 限时链接是 bearer token，拿到链接的人在到期前都可能下载，不能转发或写入公开日志。
- 安装器先核对版本清单、文件大小和 SHA-256，再解压和安装。
- 安装器复用工作台升级包自己的备份和安装后指纹核验，不自行覆盖历史项目、素材、成果或配置。
- 回滚会覆盖文件，必须单独确认，不会自动执行。

## 当前发布通道

- `stable`：只有完成 Mac 与 Windows 真机验收后才会建立；当前不存在。
