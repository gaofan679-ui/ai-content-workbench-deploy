# ChatGPT 网页伴侣

这是一条独立于 Codex 内置浏览器控制会话的 Chrome 扩展路线。它只领取本机工作台中已经明确确认上传范围的任务，复用使用者在同一 Chrome 配置中的 ChatGPT 登录状态。

当前安全边界：

- 参考图数量以内部生图请求为准；伴侣必须完整附加全部图片，不得自行截断、删减或补图。
- 每次正式生图新建一个独立 ChatGPT 对话；已提交任务的结果恢复仍留在原对话，绝不重新发送。
- 每次只提交 1 次；进入 `submitting` 后，即使页面异常也不会自动再次提交。
- 只有提示词真正进入 ChatGPT 输入状态后才允许点击发送；DOM 假写入会在发送前停止。
- 使用者在固定对话中手动发送后，伴侣会按任务校验码自动接回图片，不重新上传或再次发送。
- 恢复探测失败只延迟 10 秒重查，不再把任务永久排除；后台异常会写入扩展控制台，不再静默吞掉。
- 没有登录、输入区不可用或伴侣离线时，在占用人物生成次数前阻断。
- 同时打开多个 ChatGPT 标签页时逐个探测，优先使用真正已登录且可输入的页面，不让旧标签页造成误判。
- 候选图回传后仍需使用者确认，确认前不发布到成果中心。
- 扩展安装会改变浏览器配置，必须经过使用者单独明确同意后再执行。

## 客户启用条件

- 本组件随当前工作台提供，但属于“安装后启用”：客户需要使用自己的 Chrome 配置登录 ChatGPT，并明确同意安装浏览器扩展。
- 部署助手应先确认本地网页工作台已经启动，再引导客户在 Chrome 的扩展管理页加载本目录；不得读取、导出或复制客户的浏览器登录信息。
- 启用后必须完成一次“伴侣在线、ChatGPT 已登录、输入区可用、测试任务不重复提交”的本机验收。未通过时网页端显示“等待配置”，不能假装可用，也不能自动切换到其他付费通道。
- Edge、其他 Chromium 浏览器和 Windows 全新机尚需独立验收；没有对应证据前不得标记为全平台已验证。
